# Imagens da landing

Coloque os arquivos aqui com estes nomes. Enquanto um arquivo não existir, a página mostra o espaço reservado tracejado.

| Arquivo | Onde aparece | Formato sugerido |
|---|---|---|
| `vinicios-hero.jpg` | Hero (círculo) | quadrada, 1000×1000 |
| `vinicios-retrato.jpg` | Seção "Quem conduz" | retrato 4:5, 900×1125 |
| `depoimento-1.jpg` … `depoimento-3.jpg` | Resultados | 16:10, 1200×750 |
| `simbolo-instituto.png` | CTA final | PNG transparente, 256×256 |
